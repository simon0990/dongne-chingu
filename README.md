# 동네친구 (Dongne Chingu)

Korea Local Marketing Hackathon 2026 (11/21 토, 디캠프 마포) 출품용 지도.

- **열어 보기:** https://simon0990.github.io/dongne-chingu/ (로그인 없이 열림, 제출할 주소)
- **저장소:** https://github.com/simon0990/dongne-chingu (공개)

**문제:** 한국인 후기는 네이버 지도에, 외국인 후기는 구글 지도에 쌓인다. 외국인은 언어와 앱 장벽 때문에 한국인 후기를 못 보고, 관광객 후기만 보고 고른다.

**해법:** 장소마다 "구글 리뷰 1개당 네이버 리뷰 몇 개"(로컬 지수)를 핀에 띄운다. 주황 핀은 현지인 위주, 흰 핀은 관광객 위주다. 핀을 누르면 한국인 후기 요약(내 말로), 현지 친구 한마디(음성), 한국인이 시키는 메뉴, 주문 문장과 "직원에게 보여주기" 화면, 한국어 주소와 복사 버튼이 나온다. 영어·일본어·중국어를 지원한다.

## 사전 안내 영상·메일에서 확인한 것 (11/17 메일, 11/20 정리)

- **참가 확정 완료** (11/17 선정 → 같은 날 확정).
- **장소:** 디캠프 마포 5층 세미나실, 서울 마포구 마포대로 122 (공덕역 4번 출구 쪽). 주차 불가, 건물 전체 금연.
- **시간:** 09:30 입장 → 09:40 오프닝(규칙, Trip-Pups 문제) → 09:45 만들기 → **11:55 제출 마감** → 서로 써 보며 1차 심사 → 12:28 시상 → 12:40 마침, 13:00 퇴실. 늦게 남을 수 없다.
- **입장:** "오시는 길" 메일의 입장 QR 링크를 **당일 휴대폰에서 직접 연다.** 캡처해 두면 작동하지 않을 수 있다.
- **와이파이:** Front1_Guest (비밀번호 없음). 유선 랜 없음. 멀티탭은 주최 측 준비.
- **제출:** 참가 확정 메일의 "내 참가 페이지" 링크 → 결과물 내기 → **로그인 없이 열리는 주소**와 한 줄 설명. 내기 전에 새 창에서 열리는지 확인. ElevenLabs를 썼으면 질문 2개(어디에 어떻게 썼는지, Discord에서 Creator 쿠폰을 받았는지)가 더 나온다. **마감 전엔 몇 번이든 다시 낼 수 있으니 덜 됐어도 먼저 한 번 낸다.** 이 링크는 남에게 공유하지 않는다.
- **배포:** Claude Code로 만든 결과물은 Netlify Drop에 로그인해 폴더를 끌어다 놓으면 주소가 생긴다. 이 프로젝트는 원격에서도 올릴 수 있게 **GitHub Pages**를 쓴다(아래 "배포"). Netlify Drop은 GitHub이 안 될 때의 예비 수단으로, `app/` 폴더를 끌어다 놓으면 된다.
- **ElevenLabs Creator 쿠폰은 대회 당일에 받는다** (메일 주소 공유에 동의한 참가자, 받는 순서는 당일 안내). 그 전에는 무료 요금제로 만든다. 무료 요금제는 상업용 라이선스가 없고 음악을 내려받을 수 없다.
- **ElevenLabs 팁:** 한국어 문장에는 한국어 목소리를 쓴다(Voice Library에서 Korean 검색). 아이폰은 사용자가 누른 순간에 시작한 소리만 재생한다(이 앱은 버튼을 눌러야 재생되므로 해당 없음). 실제 폰에서 소리가 나는지는 직접 확인한다.
- **Lovable 쿠폰**은 대회 이틀 전 안내 예정이었으나 11/20 기준 메일함에서 찾지 못했다. 이 프로젝트는 Claude Code로 만들었으므로 Lovable은 필수가 아니다.
- **번지 AI** 계정은 현장에서 1인 1개 지급. 아이디어 검증·화면 설계용이라 이 프로젝트에는 필수가 아니다.
- 질문은 대회 페이지 질문 칸(모두에게 보임, 연락처 금지)이나 hi@mandeun.com.

| 경로 | 내용 |
|---|---|

| `.github/workflows/pages.yml` | `main`에 푸시하면 `app/`만 GitHub Pages로 배포 |

## 배포

`main` 브랜치에 푸시하면 GitHub Actions가 `app/` 폴더만 https://simon0990.github.io/dongne-chingu/ 에 올린다. 반영까지 보통 1–2분 걸린다(대략적인 값). 진행 상황은 저장소의 Actions 탭이나 `gh run list`로 본다.

```bash
git add -A && git commit -m "장소 데이터 갱신" && git push
```

GitHub Pages는 파일을 최대 10분 정도 브라우저에 보관할 수 있다. 장소 데이터는 매번 새로 읽게 했고, CSS·JS는 배포할 때마다 버전 꼬리표를 붙인다. 그래도 예전 화면이 보이면 새로고침한다.

## 미리보기

`AI-study/hackathons` 폴더에서 실행한다. 파일을 더블클릭해서 열면 데이터를 못 읽는다.

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory HackON/KLM/app
```

브라우저에서 http://localhost:8765 를 연다.

## 대회 전까지 할 일 (목·금)

1. **장소 7–10곳 고르기.** `places-template.md`를 채운다. 관광객이 많은 곳도 1–2곳 넣어야 주황과 흰 핀이 비교된다.
2. **사진 줄이기.** 장소당 1장, 내가 찍은 사진만 쓴다.
   ```bash
   sips -Z 1400 원본.jpg --out HackON/KLM/app/photos/장소id.jpg
   ```
3. **데이터 만들기.** Claude에게 "places-template.md로 places.json 만들어줘"라고 한다. 번역까지 넣은 뒤 샘플 3곳을 지운다.
4. **로컬 지수 기준 정하기.** 실제 숫자를 모은 뒤 `places.json`의 `thresholds`(지금은 10배·3배)를 동네에 맞게 조정한다. 보통 네이버 리뷰가 구글보다 훨씬 많아서, 숫자를 보고 정해야 한다.
5. **음성 만들기.** Creator 쿠폰은 당일에 받으므로, 미리 만들 때는 ElevenLabs 무료 계정을 쓴다. 영상 기준 한 줄에 수십 크레딧이 들었다. 설명용 목소리는 영어 등 외국어 목소리, 주문 문장용은 **한국어 목소리**로 따로 지정한다. 키는 파일에 쓰지 않는다.
   ```bash
   cd HackON/KLM
   export ELEVENLABS_API_KEY=여기에_키
   export ELEVENLABS_VOICE_ID=설명용_voice_id
   export ELEVENLABS_KO_VOICE_ID=한국어_voice_id
   python3 -I tools/make_audio.py --dry-run
   python3 -I tools/make_audio.py
   ```
   음성 파일이 없으면 앱이 브라우저 기본 음성으로 대신 읽는다.
6. **배포 확인.** GitHub Pages 주소가 로그인하지 않은 창(시크릿 창)과 휴대폰에서 열리는지 확인한다. 데이터를 바꾸면 푸시만 하면 된다.
7. **대회 페이지 열어 두기.** 대회 날 쓸 노트북의 평소 브라우저에서 참가 확정 메일의 "내 참가 페이지" 링크를 한 번 연다. 그래야 당일 "결과물 내기" 단추가 바로 보인다.
8. **가입해 둘 것.** Discord, ElevenLabs (쿠폰 수령·제출 질문에 필요). Lovable은 선택.

## 제출 질문 "ElevenLabs를 어디에 어떻게 썼는지" 답변 초안

> 장소마다 "현지 친구 한마디"를 영어·일본어·중국어 음성으로, "이렇게 말하세요" 주문 문장을 한국어 목소리로 들려줍니다. ElevenLabs Multilingual v2로 mp3를 미리 만들어, 현장 네트워크가 느려도 누르는 즉시 재생되게 했습니다.

실제로 쓴 모델과 목소리에 맞게 고친다.

## 한계와 원칙

- 리뷰 수는 손으로 확인한 값이다. 앱에 확인 날짜를 표시한다. 규모를 키우려면 데이터 제휴가 필요하다.
- 로컬 지수는 판정이 아니라 참고 지표다. 새 가게나 체인점은 숫자가 왜곡될 수 있다.
- 네이버 후기를 그대로 복사하거나 자동 수집하지 않는다. 요약은 내 말로 쓰고 원문은 링크로 연결한다.
- 지도 타일은 OpenStreetMap 기본 타일이다. 소규모 시연용으로만 쓴다.
